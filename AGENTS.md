# ondrejlangr toolbox

This project is a collection of Node.js package and apps

## Packages

- [ondrej-langr-zod-package-json](./packages/ondrej-langr-zod-package-json/package.json) - Full zod package.json schema with opinionated fields
- [tsuru](./packages/tsuru/README.md) - Simpler CLI applications with focus on code generation
- [tsuru-plugin-recommended](./packages/tsuru-plugin-recommended/README.md) - Recommended set of commands and all sorts of configurations to help you get started with tsuru

## Apps

- [susumu](./apps/susumu/AGENTS.md) - local first time tracking web application focused on simpler and straightforward time tracking for multiple projects
